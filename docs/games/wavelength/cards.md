# Wavelength card review

Candidate spectrum cards for [2v2 Wavelength](./rules.md). Goal: **100
approved**. Each card is two endpoints; the psychic's clue has to point at a
hidden spot between them.

## How to review

Change the box on each line:

- `[x]` approve
- `[-]` reject — optionally add a short note after it ("too niche", "not a real
  spectrum", "too one-sided") so the next batch avoids the same mistake
- `[ ]` untouched, treated as undecided

Every card must be football-related. Batch 1 included a `general` tag; those
cards were all rejected and the tag is dropped from here on.

What makes a good card: a spectrum where reasonable people would place the same
clue at *different* spots. If everyone agrees where "Gronk" goes, the card is too
easy; if no clue can be placed, it isn't a spectrum.
