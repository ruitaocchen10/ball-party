The Card Table

Same metaphor as before — a stack of stuff on a table between four people — but the felt drops to near-black and the cream cards become the only light surfaces in the product. Hierarchy stops being a decision: if it matters, it’s on a card. Everything else is table.

The warm green felt is gone. What’s left is a near-black with a faint green cast, lit by a single soft pool from above, so it still reads as a table under a lamp rather than as generic dark-mode chrome.

The one accent: red is the back of a card. Anything hidden is red — the unopened pack, the face-down Wavelength target, the auction’s concealed fantasy points. When a thing is revealed it turns cream. That single rule covers the mechanic your whole architecture is built around, so the colour is never decorative: red on screen always means somebody knows something you don’t.

What changed, and what I’d build first

Dropped: the animated foil sweep (it washed out the stat lines and read cheap), the paper-grain overlay, and the green felt. Cards now sit on near-black with a real shadow and a 1px top highlight, which does the “physical object” job the grain was failing to do.

The accent rule earns its keep across games. Wavelength hides one target; the auction hides FPTS: ? ? ? on every one of twenty lots. Both are the same red surface turning cream, so you build the flip once and every game inherits it. Higher-or-Lower is the same shape again — the second card’s value is a red band until you commit.

Build order I’d suggest: the card component and the red-back component first, since between them they cover the lobby, both auction states, both Wavelength states, and every reveal in the product. The dial is the only piece that’s genuinely Wavelength-specific.

One thing to check on device: cream at #F4EFE4 against #111311 is a hard bright edge in a dark room, which is right for a card on a table but can feel harsh if a screen is mostly card. Screens 1 and 4 are the test — if they glare, drop the stock to about #E8E2D5 rather than lifting the table, so the cards stay the light source.
