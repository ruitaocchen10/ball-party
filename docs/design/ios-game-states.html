Ball Party on iOS: every game state

Every screen and state the five games can be in, drawn from the SwiftUI source with the app's own tokens (Theme.swift) and kit (Foundation/UIKit). Each frame has an id: say "change atb-bid-self" and it is unambiguous. The helper functions at the top of the script mirror the kit one-for-one (panel() is PanelCard, concealed() is Concealed, and so on), so a kit-level change is a one-function edit.

Drawn from main @ 31aa802. Approximations: SF Symbols are stand-ins, NFL logos show the team-code fallback the app uses while a logo loads, headshots and avatars are placeholders, and the QB spin reel and lot reel are shown as a still mid-spin. This replaces nothing: the older ios-games-preview.html beside it still uses the retired cream panels.
